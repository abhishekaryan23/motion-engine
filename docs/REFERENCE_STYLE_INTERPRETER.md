# Reference style interpreter

MotionEngine separates deterministic measurement from visual interpretation. `reference-evidence` creates a bundle; an external multimodal orchestrator supplies the prompt, evidence, and sample images to its chosen model. The model returns one `ReferenceStyleProfile` JSON document. MotionEngine itself has no model or network dependency.

The protocol request is `interpreter-request.json` (`motionengine.reference-interpreter/0.1`). It points to the evidence and samples, includes the response schema, and declares `max_repair_attempts: 1`. On invalid output, `validate-reference-style` can write a repair request containing validation issues and the prior response. The CLI only writes that request; the external orchestrator is responsible for making at most one repair call and submitting the corrected response.

Interpret two things across the whole reference, using the closed vocabulary in the schema (`ReferenceStyleProfile` v0.2): **style** (palette, typography, material, motion feel, transitions, rhythm) and **visual construction** (the `visual_language` table: how much imagery or objects carry the story, what character they have, which composition families dominate, how ideas are explained). The prompt asks what the reference does and how much it relies on type versus visuals, never what image to make for a given story. Omit a dimension or set its value to `null` when unclear; confidence below `0.5` is retained for provenance but not applied. Never return source subject matter, visible wording, identities, logos, asset recommendations or image descriptions, frame layouts, coordinates, or timings. Audio is not analyzed, beyond whether a stream exists. Palette swatches are approximate evidence from the measured palette, not instructions to copy exact colors.

The boundary is intentionally file based: evidence and source frames go to the external interpreter, while the engine receives only the constrained profile. See [REFERENCE_EVIDENCE.md](REFERENCE_EVIDENCE.md) and [REFERENCE_STYLE_PROFILE.md](REFERENCE_STYLE_PROFILE.md).
